# diabetes-prediction-model-
# Early-Stage Diabetes Risk Prediction API

A lightweight machine learning classification model and Flask REST API built to assess early-stage diabetes risk from patient clinical symptoms.

---

## Project Structure

```text
├── app.py              # Flask API for real-time predictions
├── train.py            # Preprocessing, model training, and evaluation
├── model.joblib        # Serialized Logistic Regression pipeline artifact
├── requirements.txt    # Python package dependencies
└── README.md           # Project documentation
